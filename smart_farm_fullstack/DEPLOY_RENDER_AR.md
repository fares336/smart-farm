# نشر Smart Farm على Render (نسخة تجريبية مجانية)

## قبل النشر
- هذه نسخة Flask كاملة وليست موقعًا ثابتًا؛ اختر Web Service.
- لا ترفع ملف `.env` أو مفاتيح API إلى GitHub.
- ملف `render.yaml` يطلب من Render إنشاء `FLASK_SECRET` و`ROBOT_API_KEY` تلقائيًا.

## الخطوات
1. فك ضغط ZIP.
2. افتح المجلد `smart_farm_fullstack`.
3. أنشئ مستودع GitHub جديدًا خاصًا (Private)، وارفع **محتويات** هذا المجلد إلى جذر المستودع، وليس المجلد الأب كاملًا.
4. افتح Render وسجّل الدخول بحسابك، ثم اختر New > Blueprint إذا أردت أن يقرأ `render.yaml` تلقائيًا، أو New > Web Service.
5. اربط مستودع GitHub.
6. إذا أنشأت Web Service يدويًا، استخدم:
   - Runtime: Python 3
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `gunicorn --bind 0.0.0.0:$PORT app:app`
   - Health Check Path: `/health`
7. تأكد من وجود متغيري البيئة `FLASK_SECRET` و`ROBOT_API_KEY` بقيم طويلة وعشوائية. لا تضع مفتاح الروبوت في كود المتصفح.
8. اضغط Deploy وانتظر نجاح البناء. افتح رابط `onrender.com` الذي يظهر في لوحة Render.

## تنبيه مهم عن النسخة المجانية والبيانات
هذه الإعدادات مناسبة للعرض والتجربة فقط. خدمة Render المجانية قد تتوقف بعد 15 دقيقة من عدم الاستخدام، وملفاتها المحلية مؤقتة؛ لذلك قاعدة SQLite والصور المرفوعة قد تُفقد عند إعادة التشغيل أو النشر أو توقف الخدمة. لا تستخدمها لتخزين قراءات روبوت حقيقية أو بيانات مهمة قبل نقل قاعدة البيانات إلى تخزين دائم (مثل PostgreSQL) وضبط حفظ الصور والنسخ الاحتياطي.

## تشغيل فحص سريع
بعد النشر افتح:
`https://YOUR-SERVICE.onrender.com/health`
يجب أن ترى JSON يحتوي على `"ok": true`.

## الذكاء الاصطناعي للصور
لم نضع `requirements-ai.txt` ضمن بناء النسخة الأساسية لأن PyTorch قد يجعل النشر المجاني بطيئًا أو يتجاوز الذاكرة المتاحة. بقية الموقع وواجهات API تعمل دون تثبيت حزم الذكاء الاصطناعي. تفعيل فحص الصور على الاستضافة يحتاج خطة موارد مناسبة واختبارًا منفصلًا.
