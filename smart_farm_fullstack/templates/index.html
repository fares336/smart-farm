Robot connection

Send sensor data from ESP32.

REST API

Connection steps

  1. 01
    Connect ESP32 to Wi-Fi

    Use your network credentials in the ESP32 firmware.

  2. 02
    Set the API key

    Set ROBOT_API_KEY on the server.

  3. 03
    Post a reading

    Send JSON to /api/robot/readings.

API endpoint

POST /api/robot/readings

JSON example

{
  "robot_id": "smartfarm-01",
  "zone_id": "A1",
  "moisture": 42.5,
  "soil_temp": 23.8,
  "ph": 6.7,
  "ec": 1.2,
  "battery": 87,
  "ec_method": "ECe",
  "ec_unit": "dS/m",
  "sensor_model": "sensor model and part number",
  "calibration_date": "2026-11-10",
  "measurement_depth_cm": 10
}

Use null for unmeasured values.

Deployment requirement

The API must be hosted on a public HTTPS server.
